# Skill: Spec Compliance Checker

## Propósito
Verificar que los DTOs de Java y las interfaces de React coincidan exactamente con la especificación viva.

## Pasos:
1. Leer `.openspec/specs/manda-todo/manda-todo.spec.md`.
2. Revisar los nombres de campos en los modelos (`id_cliente`, `es_frecuente`, etc.).
3. Confirmar el uso del recargo del 50% en entregas fallidas.
