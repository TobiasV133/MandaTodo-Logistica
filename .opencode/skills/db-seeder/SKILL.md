# Skill: Database Seeder

## Propósito
Cargar los datos iniciales de prueba en la base de datos `mandatodo_db`.

## Instrucciones de ejecución:
1. Asegurar que MySQL 8.x esté corriendo en `localhost:3306`.
2. Ejecutar las sentencias de `schema.sql`.
3. Ejecutar la carga de datos desde `seeds.sql`.
